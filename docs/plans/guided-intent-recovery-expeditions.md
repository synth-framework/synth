## Proposed Mission (requires owner review)

**Restore SYNTH's guided human–agent intent-to-outcome journey.** Given an incomplete idea, an existing repository, or source documents, the operator and agent can gather relevant evidence, ask consequential contextual questions and compare options, distinguish proposals from human choices, produce an agreed and testable build brief, carry that brief into an aligned plan and implementation, and report what was actually tested and published. SYNTH is an orchestration/assurance layer, **not** automatically a code generator. No unapproved interpretation, fabricated human reviewer, unrelated workflow template, replay-only claim of app correctness, or extra promotion ceremony should count as success.

**Owner decisions before Mission approval:** (1) who is the initial operator/customer, and which representative request should be the real pilot; (2) whether the first product promise is *decision support and traceability* or *technical prevention of agent execution before authorization*. These lead to different approval/security requirements. This plan does **not** choose for the owner. User-facing simplicity, normal Git PR integration, explicit branch-local versus published state and narrower assurance claims are standing constraints in either case.
